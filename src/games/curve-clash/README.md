# Curve Clash

2–4 players. Each player is a line that never stops moving and leaves a permanent trail.
Hit a wall or any trail (yours included) and you're out. Small gaps open in every trail
every 2–3 seconds, so you can slip through. Last line alive wins the round; first to 3 rounds
(2 rounds with 3+ players) wins the match. Lines speed up slowly during a round so rounds stay short.

**Controls:** hold the ◀ / ▶ buttons in your corner (P1 bottom-left, P2 bottom-right,
P3 top-left, P4 top-right). Keyboard: your seat's left/right keys (A/D, ←/→, J/L, F/H).

Bots cast rays left/straight/right on the occupancy grid and steer toward open space.
